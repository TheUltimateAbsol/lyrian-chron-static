Planning rules & limitations

This is a local build planner, not character approval. Character creation uses the full 1000 EXP class budget (1100 for a non-hybrid Human), 300 separate breakthrough EXP, and 3 IP. Creation breakthrough EXP never contributes to Spirit Core (SC); unused creation breakthrough EXP expires.

Each normal post-creation week supplies 100 EXP. Spirit Core (SC) is EXP spent, after refunds. An IP class unlock inserts a training week with no normal EXP gain. DSF can replace the IP for tier 1 / 2; SF can replace it for tier 3 (and lower tiers). Fuel is a planned requirement, not a free supplied item. Unspent creation IP is not banked for later weeks. This schedule is an estimate, not a simulation of expeditions, lockouts, events, or weekly IP expiry.

Mirane adds 1000 Clim to the standard 3000 Clim equipment budget, limits creation item purchases to 4000 Clim each, and restricts GM-controlled classes. You receive an Adventurer’s Kit on arrival; it need not be purchased. Material restrictions and final character approval still apply. Future equipment is a wish list charged against your listed funds; this planner does not predict loot, market prices, or modded equipment.

Skill, stat, proficiency and elemental choices are tracked explicitly. Unknown narrative prerequisites require a visible GM override. The sheet calculates base stats and verified permanent bonuses, not temporary combat effects or conditional buffs. Equipment guard / penalties apply only to pieces marked equipped. Expertise names and discretionary Expert Knowledge need GM approval. Always read the complete feature rules before relying on a conditional effect.
