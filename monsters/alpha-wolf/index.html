Strategy

If not engaged in melee, the alpha wolf will move up to the most vulnerable target it can reach without provoking attacks of opportunity. It will use Leading Bite against the target if it can get wolves in range with it. If an enemy is prone, it will use Go for the throat.

Running this monster

An alpha wolf should be ran with several normal wolves to provide a good challenge for a group of adventurers. An alpha wolf cannot do much by itself and absolutely needs normal wolves around to function as an enemy.
