Appearance
A large spider covered in a thick carapace.
Habitat
The armored spider is most commonly found underground or in caves where a broodmother has set up her lair.

Strategy

The armored spider will move up and attacks the nearest enemy target, using Poison Bite whenever it can.

If it gets targeted by an attack it will use Defensive Curl, then use Block every time it can while the stance lasts.

Running this monster

The armored spider should be run in combination with other types of spiders.
