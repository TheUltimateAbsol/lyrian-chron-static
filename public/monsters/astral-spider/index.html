Appearance
A large spider whose form seems almost transparent.
Habitat
The astral spider is most commonly found underground or in caves where a broodmother has set up her lair.

Strategy

The Astral Spider will start hidden and remain hidden until an enemy has moved the range of its blink. When that happens, it will Blink onto that target, choosing the least armored one if multiple targets are available, and attack it. After that, it will use Poison Bite each time it can.

Running this monster

The astral spiders should be run with several other of the grunt spiders. Don't run too many at the same time, as an ambush from many blinks at the same time can easily leave a character dead.
